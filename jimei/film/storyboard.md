## 概要

一个累了的人，在灰色的夜里被几束很小的光接住，最后和一群人在金色麦田里重新聚拢。全片用刮刀油画，把《极美》从"灰"一刀一刀刮成"金"，结尾再刮回第一笔光。

- **画幅**：1080×1920 竖屏（抖音），24 fps，时长 211.63 s（5,079 帧），画面与音乐同起同止。
- **音乐**：《极美》原曲 flac 全程不剪不改；不加旁白，只加少量可选的刮刀音效。
- **讲解文本**：26 条小号屏幕文字，只做引导，不做大字幕；统一放在画面上方的平静色块里。
- **结构**：前奏 + 7 幕 + 尾声，共 24 个镜头；每个动作都挂在拍号 b# 上（76 BPM，一拍 0.7895 s）。
- **母题**：《极美》是孙燕姿 2017 年专辑《跳舞的梵谷》的最后一首，词由她本人写；豆瓣的介绍说歌词呼应梵高的《麦田群鸦》。片中只借"麦田 + 黑鸟"两个元素，不复刻那幅画的构图。
- **交给 Code 的三样东西**：本文档、《Impasto · Palette Knife》风格提示词、普通音质的 flac（不要全景声版本）。第 6 节是写给 Code 的技术说明。

## 故事与画面

情绪线是"灰 → 小光 → 金 → 递光 → 抬头 → 日出群聚 → 刮回第一笔光"。颜色本身就是剧情：颜色回到哪里，希望就到了哪里。

### 角色

- **旅人**：穿一件旧风衣的人，领子竖着。脸只用两三刀概括，不画五官，性别模糊，不画成任何真实的人（包括孙燕姿本人）。
- **群鸦**：黑色飞鸟。《麦田群鸦》里的乌鸦常被读作死亡，也被读作重生；这里它们是"我们"——不起眼、会走散、也会回来。每只鸟 = 1 个身体色块 + 2 片翅膀刀痕，固定种子。
- **撑伞的人、散场的人群、长椅上的人**：同样是无脸剪影。
- **第一笔光**：0.23 s 落下的那一刀暖橙。它在片中出现四次：开场、间奏的田里、静默的黑暗里、结尾唯一留下的颜色。它是全片的线头。

### 不做的事

- 不复刻《麦田群鸦》：不画三岔土路、不画压低的暗蓝风暴天，也不用梵高式漩涡笔触。
- 不用叠化：转场只用刮刀覆盖（paint-over）和卡拍硬切。
- 静止的颜料不动：只有人、鸟、伞、雨、叶、麦穗和光在动。

## 给 Code 的技术说明

顺序是：先跑音频拍点，再画参考图，最后按分镜逐镜渲染。每个动作都用拍号驱动，不要手写秒数。引擎用风格提示词里的 `impasto.js` / `plate.js`，参数见其 DEMO.md。

1. **音频与拍点**
    - 用普通音质 flac（44.1 kHz 立体声，211.63 s）。全景声（av3a）版本 ffmpeg 解不开，不要用。
    - `librosa.load(sr=22050, mono=True)` → `librosa.beat.beat_track(start_bpm=76, tightness=200)`：应得到 256 拍，b0 ≈ 0.232 s，拍距 ≈ 0.7895 s。`极美_时间轴.json` 里已有同一套拍点（`beats_s`），所有事件按 b# 查表。
    - 自己检测的结果与 json 相差超过 1 拍时，以检测结果为准，分镜按拍号整体对齐。
2. **参考图（plates）**：每个场景先画成扁平、分好明暗（至少 3 个明度）的参考插画，再用 `paintRef` 转成刀痕。尺寸 1440×2560，给推拉留余量，镜头始终在画内（half = W/2/zoom）。每张图都把 y 300–560 这条带留成平静色块放字幕。
    - P1 亚麻底色：S01、S02、S18、S23、S24
    - P2 散场夜街：S03、S06、S07、S12、S14
    - P3 路灯长椅：S04、S13
    - P4 窗口与油灯：S05
    - P5 夜空：S08、S14 上段
    - P6 麦田远景：S09、S11、S19、S20（同一张图，季节和光靠 grey / reveal / revC / 光角来变）
    - P7 麦穗与孤树近景：S10
    - P8 麦田俯视：S15、S21、S22
    - P9 山坡顶：S16、S17
3. **会动的东西**（每帧用固定种子重建，不能"沸腾"）：行人走路循环、黑鸟（1 个身体 DAB + 2 片翅膀 KNIFE，每拍拍翅 2 次）、伞、雨、落叶、麦穗摆动、颜料丝带、抛向空中的色簇。每个手势都有预备 → 动作 → 回弹。
4. **颜色事件**：S03 起世界 grey:1，第一笔和暖窗 grey:0；S05、S06、S09、S20 用 reveal 半径波铺色；S16 是同一批笔触在灰版和苍白版之间切换。
5. **标题"极美"**：用思源宋体 Heavy 把两个字渲染成遮罩，作为参考图里的一个 shape group，`paintRef` 后用 `appear` 从左到右扫 1.0 s；12.20 s 用一道横向刮痕去掉。
6. **字幕**：DOM 文字层，按"讲解文本"一节的样式和时间，不跟镜头移动。
7. **声音**：原曲是主音轨，不剪、不压缩、不重新混音；要统一响度只整体加减增益到 −14 LUFS。可选的刮刀音效用滤波噪声合成，比音乐低约 20 dB，只放在 0.23 s、12.20 s、12.86 s、69.71 s、140.76 s、170.67 s 和 b252–b255 四刀。166.90–168.40 s 不加任何声音。
8. **导出**：1080×1920，24 fps，2× 超采样，H.264 High，CRF 14–16（或 ≥ 20 Mbps），yuv420p，AAC 320 kbps / 44.1 kHz；不加胶片颗粒。文件名 `极美_刮刀油画.mp4`。封面建议截 S21 俯视的金色太阳图案（约 190 s）。
