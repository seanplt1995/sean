# 《极美》刮刀油画 MV

孙燕姿《极美》的抖音竖屏 MV（1080×1920 · 24 fps · 211.63 s · 5079 帧），刮刀油画风格。分镜、讲解文本和时间轴来自 `film/storyboard.md` 和 `film/timeline.json`。风格依据《Impasto · Palette Knife》风格提示词。

一个累了的人，在灰色的夜里被几束很小的光接住，最后和一群人在金色麦田里重新聚拢。颜色本身就是剧情：0.23 s 落下的那一笔暖橙出现四次（开场、田里的小火光、静默的黑暗里、结尾唯一留下的颜色），全片从灰一刀一刀刮成金，再刮回第一笔光。

原曲版权归原作者所有，本仓库不包含音频，也不包含成片视频。

## 生成成片

需要 Node 18+、Python 3（librosa、soundfile、scipy）、ffmpeg，以及 Playwright（`npm i -g playwright`）。

```bash
cd jimei
python3 tools/beats.py  极美.flac                 # 拍点核对：与 timeline.json 相差 < 0.12 s
python3 tools/mix.py    极美.flac mix.wav         # 原曲整体 −0.6 dB → −14 LUFS，叠加可选刮刀声（--no-sfx 关闭）
node    tools/render.mjs --audio mix.wav --out 极美_刮刀油画.mp4
```

- 没有显卡的机器上用 SwiftShader 软件渲染，约 1 s/帧，全片约 1.5 小时；`--headed` 用真实显卡会快很多。
- 分段编码（每 240 帧一段），中断后重新运行同一条命令会接着渲染。也可以把帧范围拆给两个进程并行：
  `--from 0 --to 2640` 和 `--from 2640 --to 5079`，都完成后不带范围再运行一次即合成。
- 抽帧预览：`node tools/still.mjs out/ 20 74 190`（指定秒数，输出 PNG 和缩略图拼版）。
- 浏览器预览：用本地 HTTP 服务打开 `index.html`（例如 `npx serve .`），点"音频"选 flac，再点 ▶。

导出参数：H.264 High@4.2，CRF 15（上限 45 Mbps），yuv420p，BT.709，AAC 320 kbps / 44.1 kHz，2× 超采样，无胶片颗粒。

## 怎么画的

- **刀痕**：每一笔是一个斜切两端的平面，落刀处有一道脊，起刀处有一道唇，颜料用尽处碎成条纹，两种颜色被刀拖在一起（`c`、`c2`）。高度场被侧光掠过，脊线才有体积。
- **由粗到细**：天空、墙面用 40–56 px 的大刀面，边缘和人物只用 3–7 px；笔触不越过形状组，轮廓保持清楚；下面垫一层模糊 1.5 px 的参考图做底色，不露画布。
- **颜色是事件**：每一笔都有灰版和彩版。灰城（grey:1）里只有那扇暖窗是彩色；月光、油灯、日出都是"刀把颜色一笔一笔重新铺回去"（reveal 波，颜色前沿沿着每一笔的方向推进）。
- **转场**：b16、b88、b178、b216 四个大段下拍都是刮刀覆盖（新画面一笔笔铺在旧画面上），其余是卡拍硬切，没有叠化。
- **缓存层**：静止的参考图只画一次，烘焙进世界坐标的缓存（颜色、高度、reveal 键、刀痕内位置），每帧按镜头重采样，再逐像素算灰→彩，所以缓存后的画面仍然能一笔一笔地上色。软件渲染下每帧从约 4 s 降到约 1 s。
