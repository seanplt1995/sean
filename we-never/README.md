# We Never · 流沙奇点 · 高维织物

霓虹兔《We Never》（102.48 s · 128.0 BPM）的抖音竖屏（9:16 · 1080×1920 · 60 FPS）音画同步生成艺术片。

整个作品是一个**单文件 WebGL2 程序**（`index.html`，无任何外部依赖、无 CDN），外加一个可选的离线逐帧渲染脚本（`render.mjs`），用来输出可直接上传抖音的 MP4。

---

## 快速开始

1. 用 Chrome / Edge（桌面版，最新版本）打开 `index.html`。
2. 把 `霓虹兔 - We Never.mp3` 拖进画面，或点 **选择音频 · Load MP3**。
3. 程序会先对整首歌做一次 FFT 分析（约 1 秒），再自动开始播放。

没有音频时，点 **演示模式 · Demo**，会用合成的 128 BPM 节拍网格驱动画面（无声）。

> 用本地 HTTP 服务打开（例如 `npx serve .`）时，如果把 mp3 命名为 `We Never.mp3` 放在 `index.html` 旁边，程序会自动加载，点击任意处即开始。也可以用 `index.html?audio=路径` 指定音频。

### 快捷键

| 键 | 作用 |
| :-- | :-- |
| `Space` | 播放 / 暂停 |
| `H` | 显示 / 隐藏遥测 HUD（默认隐藏，成片是纯画面） |
| `R` | 开始 / 停止录制 |
| `F` | 全屏 |
| `← / →` | 后退 / 前进 5 秒 |
| `1`–`8` | 跳到第 1–8 幕 |

控制栏（鼠标移动时出现，播放中 2.6 秒后自动隐藏）里可以切换画质（ULTRA 40.9 万 / HIGH 26.2 万 / MED 16 万 / LOW 6.5 万粒子）。

## 导出视频

### 方式 A：浏览器内录制（MediaRecorder）

控制栏右侧选择范围：**FULL 00:00–01:42** 或 **抖音切片 00:09–00:45**（规格文档推荐的 36 秒高燃切片），然后点 **● REC 60FPS**。
程序会从片头重置粒子场（切片模式会先预演 4 秒，让粒子处于正确状态），播放到结尾后自动停止并下载文件。

- 画面：`canvas.captureStream(60)`，码率 40 Mbps
- 声音：直接从 WebAudio 图（`MediaStreamAudioDestinationNode`）录制，与画面同源同步
- 格式：浏览器支持时优先输出 MP4（H.264 + AAC），否则 WebM（VP9 + Opus）

实时录制的帧率取决于显卡；如果机器跑不满 60 FPS，请用方式 B。

### 方式 B：离线逐帧渲染（推荐，画质最稳定）

每一帧都以严格的 1/60 s 步长模拟，在 GPU 上直接转成 YUV 4:2:0（BT.709），再交给 ffmpeg 编码，所以和机器性能无关，不会掉帧。

```bash
cd we-never
npm i playwright            # 只需一次
npx playwright install chromium
# 需要系统里有 ffmpeg

# 完整版（--headed 会打开一个浏览器窗口，使用真实显卡，速度快很多）
node render.mjs --audio "霓虹兔 - We Never.mp3" --out WeNever_full_1080x1920_60fps.mp4 --headed

# 抖音 36 秒切片
node render.mjs --audio "霓虹兔 - We Never.mp3" --from 9.04 --to 45.04 --out WeNever_cut_09-45.mp4 --headed

# 预览：每 30 帧导出一张 PNG
node render.mjs --audio "霓虹兔 - We Never.mp3" --fps 10 --png preview --every 5
```

其他参数：`--fps 60`、`--q ultra|high|medium|low`、`--hud 1`（把遥测 HUD 烧录进视频，默认不烧录）、`--exposure 1.2`（整体曝光微调）、`--crf 18`（x264 质量，越小越好）、`--gpu`（无窗口但尝试使用显卡）。
没有显卡的服务器上也能跑（走 SwiftShader 软件渲染），大约 0.7 秒一帧。

## 时间轴（实测）

用 STFT 频谱通量和节拍梳状滤波重新测了一遍原曲：速度确实是 **128.0 BPM**，节拍相位 0.04 s，每 8 小节正好 15 s。第二段 Drop 比整小节早一拍（弱起），所以从 **59.57 s** 开始。

| 幕 | 时间 | 粒子系统 | 关键卡点 |
| :-- | :-- | :-- | :-- |
| I 序章·暗涌 | 0.00–9.04 | 金沙细流落在隐形球面力场上，沿各自的经线铺开成沙幕 | 每个检测到的 808 都在球面上激起一圈测地线冲击环 |
| II 浑天星盘·冰晶蓄力 | 9.04–15.04 | 七重同心异向旋转的浑天仪流沙星环（莫比乌斯丝带、三股编织、5° 刻度）→ 13.5 s 化作全屏六方冰晶分形矩阵，镜头推入，径向光束 | 13.2 s 低音抽空；15.04 s 冰晶矩阵引爆 |
| III 双螺旋星云沙暴 | 15.04–30.04 | 起爆冲击波 → 双螺旋龙卷（旋度噪声）→ 22.5 s 起全部汇入洛伦兹吸引子 | 28.0–30.0 s 军鼓滚奏：8 重万花筒，每一击换切角并瞬态提亮 |
| IV 四维霍普夫流光织物 | 30.04–45.04 | 四维霍普夫纤维丛：6 层嵌套环面 × 5 条丝带，4D 旋转后球极投影，贯穿全屏 | 每个 808 沿纤维发出光脉冲；43 s 滚奏时纤维加速 + 8 重万花筒 |
| V 深海虹彩丝绸·克拉尼漩涡 | 45.04–59.57 | 三层薄膜干涉丝绸，景深虚化；每个拨弦起音激起一圈涟漪 | 57.5 s 丝绸折叠成全屏克拉尼声学共振纹，模态渐变并加速旋转，59.57 s 直接变形为四维方块 |
| VI 超正方体星核·戴森纽结环 | 59.57–75.04 | 黄金四维超正方体内核；外层是 (5,8)/(7,11)/(3,7) 三股编织环面纽结，60° 交错逆向旋转；外立方体 8 个顶点喷出螺旋流沙 | 每个 kick 从内核喷出火花雨 |
| VII 万花筒曼陀罗穹顶 | 75.04–89.57 | 8 层黄金角（137.5°）叶序 + 玫瑰窗环/辐条组成无限隧道，6 重镜像对称，外圈 25% 暖金 / 冰青高光沙粒 | 87.5–89.4 s 滚奏时隧道与旋转加速到峰值 |
| VIII 流金丝带·余烬循环 | 89.57–102.48 | 香槟金与银白流沙丝带层流垂落 | 99 s 起收束为顶部中央一道细流，102.48 s 归黑，与片头金沙细流无缝循环 |

音频驱动：

- **低频 20–120 Hz**：粒子亮度、冲击波、相机震动、色散、隧道速度
- **中频 300–2500 Hz**：旋度噪声强度、丝绸涟漪（中频起音）、背景星云
- **高频 4–16 kHz**：洛伦兹湍流、液滴迸散、万花筒切角（高频起音）

实时播放时电平来自 `AnalyserNode`（FFT 2048，Blackman 窗）；kick / 军鼓 / 拨弦的起音时刻在加载时对整首歌离线检测（频带对数谱通量 + 自适应阈值），所以卡点没有检测延迟，离线渲染和实时播放的结果一致。

## 技术结构

全部在 `index.html` 里，原生 WebGL2，不依赖 Three.js：

- **GPGPU 粒子**：3 张 RGBA32F 纹理（位置 / 速度 / 辅助通道），用 MRT 乒乓更新；每一幕编译一个专用的物理着色器
- **力场**：带解析梯度的 3D simplex 噪声 → 无散度旋度噪声；洛伦兹 ODE；陀螺仪曲面的牛顿投影；4D 旋转 + 透视投影；黄金角叶序
- **Gray-Scott 反应扩散**（256²，每帧 4 次迭代，kick 时注入新的生长点）：给粒子染色，也作为背景的发光脉络
- **背景**（¼ 分辨率）：域扭曲 FBM 星云、光线步进的陀螺仪辉光、星点
- **后期**：HDR 拖尾反馈、双 Kawase 泛光、径向色散、万花筒、奇点光晕、ACES 色调映射、胶片颗粒、暗角
- **HUD**：2D canvas 绘制 0.5 px 发丝线、遥测数据（BPM、时间、小节、BASS/MID/HIGH_RMS、`PARTICLE_ENTROPY`；画面中不出现片名字样），作为纹理合成进画面；默认隐藏（成片无任何文字），按 `H` 打开后也会被录进视频。粒子熵是对 1/64 分辨率亮度图异步回读后计算的香农熵
- 光学中心放在画面上方 45% 处（镜头偏移），避开抖音底部文案和右侧按钮区
