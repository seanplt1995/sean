# 全球实时新闻雷达

一个纯前端网页应用，用于实时查看世界各地区热门新闻排行，并提供主流新闻网站的快捷入口。

## 功能
- 各地区（全球、北美、欧洲、亚洲、中东、非洲、拉美）新闻热榜。
- 按发布时间排序，默认显示前 10 条热点新闻。
- 聚合 Reuters、BBC、AP、CNN、NYTimes、Al Jazeera 等主流媒体入口。
- 支持手动刷新与每 5 分钟自动刷新。

## 本地运行
直接用任意静态服务器启动：

```bash
python3 -m http.server 8080
```

然后访问：

`http://localhost:8080`

## 数据来源说明
- 热榜数据来自 Google News RSS，不同地区使用不同语言/国家参数。
- 为了便于前端读取 RSS，使用 `allorigins` 代理进行跨域请求。
